# CRM 亮点

CRM 按销售和服务两条线建：线索、客户、联系人、商机，以及工单、活动和知识库。

1. **线索可以一次转成客户、联系人和商机。** 不用在三个页面各建一遍。
2. **商机阶段由系统往前推一档。** 调用方只指出是哪张商机，不用自己猜下一阶段。重复请求停在同一阶段。
3. **工单升级也是一档一档走。** 按工单号升级优先级，并保留 SLA 和评论。同一次升级不会因为重复点击连跳两级。
4. **客户 360 把销售和服务放在一个客户下。** 看商机的同时能看到工单，而不是两套客户主数据。
5. **控制塔按步推进，关单单独做。** 推进和升级必须带开放密钥，谈判之后不会自动变成赢单。赢单、丢单是单独指令，丢单要写原因。控制塔不建线索、不改客户。
